REPONSES - ETAPE 7

1. Quel est le nom exact du fichier .jar créé par mvn package ? Avec quelles balises du pom.xml Maven l'a-t-il construit ?

   Le nom exact du fichier JAR est : tp-maven-produits-1.0-SNAPSHOT.jar

   Maven l'a construit avec les balises :
   - <artifactId>tp-maven-produits</artifactId>
   - <version>1.0-SNAPSHOT</version>

   Les extensions par défaut du nom du JAR sont l'ArtifactId, suivi de la Version.

2. Que se passe-t-il si vous lancez mvn package alors qu'un test échoue ?

   Maven lance la compilation et les tests avant de créer le JAR. Si un test échoue,
   Maven affiche BUILD FAILURE et le fichier JAR n'est pas créé.
